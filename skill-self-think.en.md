# Skill Enhancement Notes (English Companion)

This file is the English companion of `skill-self-think.md`.

## Core Direction
Upgrade from a domain-only skill to a project-level engineering harness:
- phase routing
- output artifacts
- explicit completion states
- browser-grounded verification
- policy and memory feedback loops

## Influences
- Harness engineering mindset: environment and feedback loops matter as much as model quality.
- Team-style workflow routing: think -> plan -> build -> review -> test -> ship -> retro.
- Long-running task reliability: progress files, feature tracking, and restart resilience.

## Practical Additions
- Session start protocol
- Completion status protocol (`DONE`, `DONE_WITH_CONCERNS`, `BLOCKED`, `NEEDS_CONTEXT`)
- Artifact metadata requirements (`trace_id`, `commit_sha`, `tool_version`)
- Policy-driven safety boundaries for repair automation

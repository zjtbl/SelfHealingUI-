# PHASE-07-ENTERPRISE-GOVERNANCE-VERIFICATION

## Required Checks
1. `E07-01` Audit fields are mandatory for each run and patch event.
   Evidence: run schema and sample records.
2. `E07-02` Sensitive artifacts have masking and retention policy.
   Evidence: policy document and sanitizer output.
3. `E07-03` KPI metrics are defined with data source mapping.
   Evidence: KPI specification and query definitions.
4. `E07-04` Governance review cadence is documented.
   Evidence: governance operating checklist.

## Pass Rule
All four checks must pass.

## Reviewer
Platform governance owner.

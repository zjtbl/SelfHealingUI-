# PHASE-05-JAVA-PATCH-GOVERNANCE

## Objective
Govern patch generation and approval paths for safe Java automation updates.

## Inputs
- Validated locator candidates
- Patch policy rules
- Review workflow configuration

## Outputs
- Minimal and auditable Java patch diffs
- L1/L2/L3 classification on each patch
- Review decision records

## Exit Criteria
- L1 patches can be generated consistently with passing rerun evidence.
- L2/L3 routes are blocked for human approval.

## Out of Scope
- Autonomous merge without policy checks.

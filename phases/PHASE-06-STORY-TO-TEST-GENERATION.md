# PHASE-06-STORY-TO-TEST-GENERATION

## Objective
Generate BDD-first test drafts for new story cards and changed UI flows.

## Inputs
- Story card and acceptance criteria
- Related frontend changes and runtime evidence
- Historical scenario and step-definition corpus

## Outputs
- Gherkin draft scenarios
- Reuse plan for existing steps
- Optional Java draft for missing automation pieces

## Exit Criteria
- At least one story card produces reviewable BDD + Java draft artifacts.
- Human review flow is enforced before merge.

## Out of Scope
- Fully autonomous scenario publishing.

# EXECUTION_WORKFLOWS.md（中文）

## 流程 A：基线绑定
1. 绑定前端仓库与自动化仓库。
2. 建立 route-page-scenario 映射。
3. 导出初始 locator 清单。
4. 验证一次端到端基线运行。

## 流程 B：失败自愈闭环
1. 解析失败日志并分类。
2. 采集页面运行态证据。
3. 召回历史元素画像。
4. 生成 locator 候选。
5. 在浏览器运行态验证候选。
6. 生成最小 Java 补丁。
7. 重跑受影响场景。
8. 持久化证据与报告。

## 流程 C：PR 影响分析
1. 解析前端 diff。
2. 识别受影响组件/路由/元素。
3. 通过图谱映射受影响场景。
4. 计算风险分并选择最小回归集。
5. 执行回归并将失败路由到自愈流程。

## 流程 D：故事卡到测试草稿
1. 解析故事卡与验收标准。
2. 关联新增/变更路由和运行态证据。
3. 召回相似历史场景。
4. 先生成 BDD 草稿。
5. 尽量复用已有 step definition。
6. 仅对缺失部分生成 Java 草稿。
7. 合并前必须人工审查。

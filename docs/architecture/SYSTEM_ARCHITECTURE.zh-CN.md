# SYSTEM_ARCHITECTURE.md（中文）

## 架构风格
采用混合架构：
- 规则引擎负责确定性门禁
- LLM agent 负责意图理解与候选生成
- Playwright 运行态负责真实浏览器验证
- 知识资产负责长期记忆与可追溯性

## 分层模型
1. 触发层
2. 决策层（编排/状态图）
3. 自愈层（分析/修复/补丁）
4. 执行层（Java + BDD + Playwright Runner）
5. 记录层（运行状态与诊断记录）
6. 知识层（结构化 + 向量 + 对象证据）

## 核心流程
- 主动流程：PR diff -> 影响预测 -> 最小回归集合
- 被动流程：失败 -> 候选生成 -> 运行验证 -> 补丁 -> 重跑

## 信任边界
- LLM 输出在运行验证通过前均不可信。
- 补丁在重跑证据通过前均不可信。
- L2/L3 变更在人审通过前均不可信。

## 数据域
- 结构化库：页面、元素、场景、运行、修复事件
- 向量库：step/element/failure 语义召回
- 证据库：截图、trace、DOM、a11y 快照、补丁 diff

## 可靠性原则
- 每次运行唯一 trace ID
- 证据写入幂等
- 显式重试策略
- 失败分类可确定
